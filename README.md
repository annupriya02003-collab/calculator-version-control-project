# Calculator GitHub Project

A simple Node.js calculator project created to demonstrate:

- Git version control
- Repository commits
- Branching and merging
- Automated testing with Jest
- Continuous Integration using GitHub Actions

## Functions

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero validation

## Run the project

Install dependencies:

```bash
npm install
```

Run automated tests:

```bash
npm test
```

## Git workflow demonstrated

1. Create repository
2. Make an initial commit
3. Create a feature branch
4. Add calculator functionality
5. Commit changes
6. Merge the feature branch into main
7. Push the repository to GitHub
8. Run automated tests

## Testing

The project contains five Jest test cases covering the calculator functions and division-by-zero error handling.

## CI

GitHub Actions automatically runs `npm test` whenever code is pushed or a pull request is created.
